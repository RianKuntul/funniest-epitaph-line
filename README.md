# Funniest Epitaph Line

A one-line tombstone epitaph of famous last words, written to `entry.txt` by a tiny deterministic Node program.

## What it does

Writes a single epitaph of famous last words — one line, at most 150 characters, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).

## Run

```sh
node main.ts
```
